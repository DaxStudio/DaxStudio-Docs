DAX Studio 3.7.0-pre

Updates

  • added Comment Script for automating query sessions with --> commands
  • added a preview of the new ANTLR-based DAX parser and code completion engine
  • added IntelliSense for Comment Script commands, script variables, and query-defined functions
  • improved Model Diagram filtering by discovering tables directly from query dependencies
  • improved Power BI Desktop discovery performance and reliability
  • improved metadata loading to reduce UI stalls when connecting or changing databases

Fixes

  • fixed DAX completion insertion after spaces, commas, and opening parentheses
  • fixed switching the new DAX parser option requiring documents to be reopened
  • fixed crash recovery files from one DAX Studio instance being removed when another instance closed
  • fixed UC_RENDERTHREADFAILURE crash handling
  • fixed connection string handling for special characters, token authentication, RLS, and Power BI endpoints
  • fixed Clear Cache execution consistency in scripts
  • fixed stale or incomplete table selection when opening Model Diagram from a query
  • fixed the Query Builder expression editor using a different font size from the main editor
  • fixed ribbon keyboard focus visual artifacts
  • fixed the VertiPaq Analyzer menu intercepting keyboard navigation
  • removed test framework artifacts from release packages
