v3.6.0

DAX Studio 3.6.0

Updates

  • added the Delta Analyzer preview for inspecting Delta table metadata behind Direct Lake models
  • added the Browse Workspaces preview
  • added the benchmark command to dscmd (thanks @savoy9)
  • added support for DAX user-defined functions when expanding measures and dependencies

  • made daxstudio and dscmd command-line arguments case-insensitive and consolidated parsing on Spectre.Console.Cli
  • moved version notifications into the main window and added opt-in preview release notifications
  • added search to File > Open and improved the Browse Workspaces experience
  • added bulk Order By controls to the Query Builder
  • added multi-row copy support to the Physical and Logical Query Plan panes
  • added zoom support to the Server Timings and Custom Trace panes
  • updated Fluent.Ribbon to v11
  • updated the DAX Formatter endpoint, migrated to Microsoft.Data.SqlClient, and replaced WebRequest/WebClient with a shared HttpClient
  • improved startup responsiveness by loading query history asynchronously
  • improved View As reconnect and trace handling
  • converted the solution to SDK-style projects with .NET Framework and .NET 8 builds
  • updated the installer to overwrite all files during upgrades

  • fixed View As reconnect races, remap caching, and stale busy states

  • fixed the trace column cache not refreshing after reconnecting
  • fixed an edge case with Server Timings and Clear Cache on Run when events arrive out of order

  • fixed dscmd dependency binding errors

  • fixed a race condition when building the options list
  • improved opening SQL Profiler and Excel version detection
